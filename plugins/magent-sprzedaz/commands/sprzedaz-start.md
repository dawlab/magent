# Start obszaru: Sprzedaż

Właściciel zainstalował plugin `magent-sprzedaz` i uruchamia go w module kursu.

## 1. Wyjaśnij krótko, co robi
Sprzedaż łapie kontakt, dogrzewa i sprowadza klientów z powrotem: lead magnet + copy landingu, sekwencje maili i newsletter, wiadomości reaktywacyjne, skrypty DM. Oddaje gotowy tekst do wklejenia. **Nie wysyła.** Brzmienie nadaje `@głos`.

## 2. Zarejestruj obszar
Dopisz do `system/obszary-zainstalowane.md` (sekcja „## Obszary"), zastępując placeholder jeśli trzeba, i zaktualizuj datę na górze:

```
- **Sprzedaż** (plugin `magent-sprzedaz`) — zainstalowany [dzisiejsza data], skonfigurowany tak. Narzędzie: [brak — tryb bez API].
```

## 3. Tryb narzędzia
Domyślnie **tryb bez API**: oddajesz tekst do wklejenia, a formularz, zapis i wysyłkę robi właściciel w swoim narzędziu. Konektor mailingowy (np. MailerLite, odczyt listy i statystyk) to krok roadmapy — gdy będzie, wysyłka i tak zostaje za kliknięciem. Szczegóły: `POLACZENIA.md`. Na teraz zostaw status „brak — tryb bez API".

## 4. Zaproponuj pierwszy ruch
Zaproponuj jeden krok pasujący do `dane/` — np. jeden lead magnet (pomysł + pełna treść + copy landingu) albo prostą sekwencję powitalną. Nie rób wszystkiego naraz.

## Granica
Przygotowanie treści — swobodnie. Zapis kontaktów i każda wysyłka — po stronie właściciela, przez kolejkę decyzji.
