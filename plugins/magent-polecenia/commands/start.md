# Start obszaru: Polecenia

Właściciel zainstalował plugin `magent-polecenia` i uruchamia go w module kursu.

## 1. Wyjaśnij krótko, co robi
Polecenia sprawia, że inni przyprowadzają klientów: mechanika i skrypty poleceń, dobór typów partnerów z tą samą personą, wiadomości partnerskie, briefy współpracy z twórcami. **„Kto" (klienci, partnerzy) wskazuje właściciel** — obszar daje system i teksty. Nie kontaktuje się za właściciela.

## 2. Zarejestruj obszar
Dopisz do `system/obszary-zainstalowane.md` (sekcja „## Obszary"), zastępując placeholder jeśli trzeba, i zaktualizuj datę na górze:

```
- **Polecenia** (plugin `magent-polecenia`) — zainstalowany [dzisiejsza data], skonfigurowany tak. Narzędzie: [brak — obszar bez narzędzia].
```

## 3. Tryb narzędzia
Ten obszar **nie ma narzędzia zewnętrznego** — z założenia. Tracking poleceń prowadzi się prostą listą ręcznie. Nie ma tu nic do podłączania; zostaw status „brak — obszar bez narzędzia".

## 4. Zaproponuj pierwszy ruch
Zaproponuj jeden krok pasujący do `dane/` — np. mechanikę i skrypt prośby o polecenie (kiedy prosić, o co dokładnie: 2–3 firmy podobne profilem) do użycia po najbliższej udanej współpracy. Poproś właściciela o wskazanie kilku zadowolonych klientów albo potencjalnych partnerów.

## Granica
Teksty i system — swobodnie. Realny kontakt z poleconymi i partnerami oraz wszelka wysyłka — po stronie właściciela, przez kolejkę decyzji.
