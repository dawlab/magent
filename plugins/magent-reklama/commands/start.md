# Start obszaru: Reklama płatna

Właściciel zainstalował plugin `magent-reklama` i uruchamia go w module kursu. To obszar **warunkowy** — nie każdy klient powinien go teraz odpalać.

## 1. Sprawdź warunek uruchomienia
Reklama ma sens tylko, gdy: (1) jest budżet, ORAZ (2) ruch organiczny/relacyjny już zamienia się w klientów. Reklama skaluje to, co działa — nie ratuje tego, co nie działa. Jeśli warunek niespełniony, powiedz to wprost i zaproponuj, żeby najpierw doprowadzić do wyniku inny obszar. Sprawdź też `dane/profil.md` pod kątem ograniczeń reklamy w branży (medyczna, prawnicza) — jeśli są, zapytaj, co wolno, i nie ruszaj kampanii bez potwierdzenia.

## 2. Wyjaśnij krótko, co robi
Reklama projektuje płatne dotarcie: copy i warianty hooków, brief kreatywny, sugestie audience/słów kluczowych, struktura kampanii i budżetu testowego. **Design-only** — zakładania i optymalizacji kampanii nie robi (to właściciel w Meta/Google).

## 3. Zarejestruj obszar
Dopisz do `system/obszary-zainstalowane.md` (sekcja „## Obszary"), zastępując placeholder jeśli trzeba, i zaktualizuj datę na górze:

```
- **Reklama płatna** (plugin `magent-reklama`) — zainstalowany [dzisiejsza data], skonfigurowany tak. Narzędzie: [Google Ads + Search Console — niepodłączone / podłączone].
```

## 4. Zapytaj o tryb narzędzia
Zapytaj, czy podłączyć **Google Ads + Search Console** (odczyt metryk: koszt leada, konwersje, frazy — pod rekomendacje optymalizacyjne).
- Chce teraz → skieruj do `POLACZENIA.md` w tym pluginie. Po podłączeniu zmień status na „podłączone".
- Nie teraz → **tryb bez narzędzia**: projektuję kampanię, wyniki z panelu podaje właściciel.

## 5. Zaproponuj pierwszy ruch
Jeśli warunek spełniony — zaproponuj jeden test: jeden kanał, jedna oferta, mały budżet testowy, jasny próg „działa / nie działa" + instrukcja ustawienia krok po kroku dla właściciela.

## Granica
Odczyt metryk — swobodnie. Założenie/zmiana kampanii, budżet, wgranie kreacji, publikacja — zawsze po stronie właściciela, przez kolejkę decyzji.
